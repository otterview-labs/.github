# Otterview Labs

We build self-hosted software for developer workflows and visual search.

我们开发面向开发工作流与视觉检索的自托管软件。

## Projects / 项目

- [Agent Session Bridge](https://github.com/otterview-labs/agent-session-bridge) — Manage local
  Codex, Claude Code, and Gemini CLI sessions with tmux, a web UI, CLI, and HTTP API.  
  通过 tmux、Web UI、CLI 和 HTTP API 管理本地 Codex、Claude Code 与 Gemini CLI 会话。

- [SightIndex](https://github.com/otterview-labs/SightIndex) — Index and search images, videos,
  and camera streams on your own infrastructure.  
  在自有基础设施上索引和检索图像、视频与摄像头流。

Licensing and deployment requirements are documented in each repository.  
许可与部署要求以各仓库文档为准。
